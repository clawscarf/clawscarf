# Shared HTTP transport

`http/` is the unmodified fetch transport generated by the pinned
`@hey-api/openapi-ts`. Regenerate it with `pnpm http:generate`.
`pnpm codegen:check` checks it together with the three API clients.

Access, Connections and the Connections plugin keep separate API methods and types.
Their generator configurations use `bundle: false` and the supported `output.module.resolve`
hook to reference this transport. No emitted imports or transport helpers are patched.
The standalone fetch npm package is deprecated and is not a dependency.

The plugin stages this source into ignored `generated/http/` inputs before compiling;
its published artifact contains the transport and its license. Service builds and
the operator archive include the shared compiled module. No new service, runtime
package or network hop is introduced.
